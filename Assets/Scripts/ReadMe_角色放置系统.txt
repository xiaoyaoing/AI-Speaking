角色放置系统使用说明
================

一、功能概述
------------
本系统提供了以下功能：
1. 在场景中的椅子上随机放置人物角色
2. 可以设置人物覆盖率（放置人物的椅子比例）
3. 可以选择人物装扮（夏装或秋装）
4. 可以设置男女比例
5. 可以播放所有角色的所有动画，查看效果
6. 可以选择播放特定动画
7. 可以设置动画播放时长和角色旋转

二、系统组件
------------
系统包含以下脚本组件：
1. CharacterPlacementEditor - 编辑器窗口，用于在编辑模式下放置人物
2. CharacterPlacementManager - 运行时管理人物放置的组件
3. CharacterAnimationPlayer - 负责播放角色动画的组件
4. CharacterPlacementUIPanel - UI界面控制脚本
5. CharacterPlacementSystem - 整合以上组件的系统脚本

三、使用方法
------------
### 1. 编辑器模式使用
- 通过菜单 "工具/人物椅子放置工具" 打开编辑器窗口
- 设置人物覆盖率、装扮类型和男女比例
- 点击"放置人物"按钮在场景中放置角色
- 点击"清除已放置人物"按钮清除场景中的角色

### 2. 创建游戏内UI系统
- 通过菜单 "工具/创建角色放置系统" 创建系统GameObject
- 创建一个UI Canvas并设置好UI控件：
  - 覆盖率滑动条和文本
  - 夏装/秋装切换按钮
  - 男女比例滑动条和文本
  - 放置/清除按钮
  - 动画播放/停止按钮
  - 动画选择下拉菜单
  - 动画时长滑动条和文本
  - 角色旋转开关
- 添加CharacterPlacementUIPanel组件到UI面板
- 将UI控件拖放到对应的引用中
- 将CharacterPlacementSystem脚本中的引用设置好

### 3. 运行游戏时使用
- 点击"放置人物"在场景中添加角色
- 调整覆盖率、装扮和男女比例参数
- 点击"播放动画"查看所有角色的动画序列
- 从下拉菜单中选择特定动画并播放
- 调整动画播放时长和角色旋转设置

四、可用动画列表
--------------
系统预设的动画名称包括：
- idle1 - 站立姿势1
- idle2 - 站立姿势2
- walk - 走路
- run - 跑步
- talk1 - 说话1
- talk2 - 说话2
- listen - 聆听
- claphands - 鼓掌
- cheer - 欢呼

五、注意事项
-----------
1. 确保场景中存在椅子对象，系统会自动查找名称中包含"Chair"的对象
2. 角色预制体需要存在于Assets/Citizens PRO/People Prefabs/路径下
3. 人物预制体需要有Animator组件并使用正确的动画控制器
4. 在播放动画前，先确保场景中已放置了人物角色

六、自定义扩展
------------
1. 添加更多动画：
   - 修改CharacterAnimationPlayer脚本中的commonAnimationNames数组

2. 添加更多人物类型：
   - 在CharacterPlacementManager脚本中添加新的预制体列表
   - 修改UI面板以支持新的人物类型选择

3. 自定义椅子查找规则：
   - 修改CharacterPlacementManager中的FindChairsInScene方法
