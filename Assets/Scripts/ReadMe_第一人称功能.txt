角色第一人称视角功能使用说明
============================

一、功能概述
-----------
本功能提供了让摄像机跟随角色并实现第一人称视角的能力。主要特点包括：

1. 切换到任意角色的第一人称视角
2. 使用鼠标控制视角的旋转
3. 在多个角色之间快速切换
4. 可通过按键或UI按钮激活/禁用第一人称视角

二、使用方法
-----------

### 1. 基本设置

将以下脚本添加到场景中的一个空物体上（推荐命名为"FirstPersonController"）：

```csharp
CharacterFirstPersonController
```

该控制器会自动查找场景中的相机和角色，但你也可以手动指定：
- 主相机：用于在非第一人称模式下显示场景
- 第一人称相机预制体：可选，如不指定将自动创建
- 是否自动选择最近角色：默认为true，会自动选择最近的角色作为初始角色

### 2. 键盘快捷键

- F键：切换第一人称视角
- Tab键：切换到下一个角色
- ESC键：解锁/锁定鼠标

### 3. UI按钮（可选）

若要添加UI按钮控制，可以：
1. 创建一个UI按钮
2. 为按钮添加 `FirstPersonViewButton` 脚本
3. 设置 `Button Text` 引用（可选，用于显示当前状态）
4. 设置 `Fp Controller` 引用（可选，默认会自动查找）

### 4. 第一人称视角控制

在第一人称视角模式下：
- 使用鼠标上下左右移动可控制视角旋转
- 视角会自动跟随角色的位置
- 默认鼠标会被锁定（按ESC可解锁）

三、调整参数
-----------

### 1. FirstPersonCameraController 参数

- 相机偏移量：调整相机与角色头部的相对位置
- 旋转速度：调整鼠标控制视角旋转的灵敏度
- 是否锁定鼠标：是否在启用第一人称视角时锁定鼠标
- 视角限制：限制视角上下旋转的角度范围

### 2. CharacterFirstPersonController 参数

- 自动选择：是否在启动时自动选择最近的角色
- 切换角色的按键：更改切换到下一个角色的快捷键

四、注意事项
-----------

1. 确保场景中存在 `CharacterAnimationPlayer` 组件，否则无法自动查找角色
2. 第一人称视角最好在放置了角色后再启用
3. 如果需要角色移动功能，需要另外编写角色移动控制脚本
4. 若要禁用鼠标锁定，可在 FirstPersonCameraController 中设置 lockCursor = false

五、常见问题
-----------

1. 问题：启用第一人称视角后看不到任何东西
   解决：检查是否正确设置了角色和相机，确保角色有可见的模型

2. 问题：相机位置不正确
   解决：调整 cameraOffset 参数，确保相机位于角色头部适当位置

3. 问题：无法切换角色
   解决：确保场景中已放置多个角色，并且 CharacterAnimationPlayer 正确引用了这些角色

4. 问题：视角移动太快/太慢
   解决：调整 rotationSpeed 参数
